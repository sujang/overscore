# v1.3.5 リリースノート（App Store提出用）

```
• 元動画のフレームレートが正しく認識されず、30FPSの動画が60FPSとして扱われることがある問題を修正しました。動画一覧の表示も、書き出される動画も、元の動画どおりのフレームレートになります

• スローモーションなど120FPS・240FPSで撮影した動画にスコアボードを重ねて書き出す場合は、60FPSで書き出すようになりました。書き出しにかかる時間とファイルサイズが極端に大きくなるのを防ぎます。スコアボードを重ねずに書き出す場合は元のフレームレートのままです

• 写真ライブラリから動画を取り込んだあと、一時ファイルが端末に残り続け、アプリから動画を削除しても空き容量が戻らないことがある問題を修正しました。これまでに溜まったファイルも、アプリ起動時に自動で削除されます
```
