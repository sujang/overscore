# v1.3.6 Release Notes (for App Store submission)

```
• Importing video from the photo library is now much faster. HEVC video shot on iPhone used to be converted during import, which could take several minutes for long videos. It is now imported in its original format

• Importing from the photo library now shows its progress as a percentage, so you can see how far along it is even when an import takes a while, such as with videos edited in the Photos app

• Fixed an issue where 4K video shot at 60 FPS or 50 FPS was exported at 30 FPS or 25 FPS when a scoreboard was added. Such videos are now exported in HEVC format so they keep their original frame rate

• The list of imported videos now shows each video's file size, resolution, and frame rate

• The export confirmation screen now shows the resolution, frame rate, and estimated file size of the exported video

• "Merge Videos Only" now exports in a format that plays on more devices, even when the videos being merged are in different formats
```
