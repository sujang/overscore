# v1.3.6 リリースノート（App Store提出用）

```
• 写真ライブラリからの動画の取り込みが速くなりました。iPhoneで撮影したHEVC形式の動画は、これまで取り込み時に形式の変換が行われ、長い動画では数分〜10分ほどかかっていましたが、元の形式のまま取り込むようになりました

• 写真ライブラリからの取り込み中に、進み具合をパーセントで表示するようになりました。写真アプリで編集した動画など、取り込みに時間がかかる場合も残り時間の目安がわかります

• 4K 60FPS・50FPSの動画にスコアボードを重ねて書き出すと、30FPS・25FPSに落ちてしまう問題を修正しました。元のフレームレートのまま書き出せるよう、このような動画はHEVC形式で書き出します

• 取り込んだ動画の一覧に、ファイルサイズ・解像度・フレームレートを表示するようになりました

• エクスポートの確認画面に、書き出される動画の解像度・フレームレート・予想ファイルサイズを表示するようになりました

• 「動画のみ結合」で形式の異なる動画を結合した場合も、多くの機器で再生できる形式で書き出すようになりました
```
