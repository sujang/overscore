# v1.3.7 Release Notes (for App Store submission)

```
• In penalty shootouts, the team that kicks first is now shown on the top row. This applies to both the scoreboard in exported videos and the match details screen

• The goal buttons on the score editing screen are now shown in each team's color. If no team color is set, they are shown in blue and red as before

• The goal markers on the score editing screen's timeline are now also shown in each team's color
```
