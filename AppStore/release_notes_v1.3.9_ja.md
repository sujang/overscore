# v1.3.9 リリースノート（App Store提出用）

```
• 過去に入力したホームチームのチーム名とチームカラーを、一覧から選んで入力できるようになりました。新規試合の作成画面とスコアボード設定画面の「ホームを過去のチームから選ぶ」から利用できます

• 一覧に表示されるチームは、試合の作成時やスコアボード設定の保存時に自動で登録されます。不要なチームはスワイプで削除できます

• 動画の読み込みに時間がかかった際に画面が自動ロックされ、アプリが終了してしまう問題を修正しました。読み込み中は画面が自動でロックされなくなります

• iOS 26以降では、動画の読み込みの進捗がロック画面などにも表示されるようになりました

• 新しい試合の作成中にアプリが終了した場合でも、入力したチーム名や読み込み済みの動画が保存され、次回起動時に試合一覧から続きを再開できるようになりました
```
